# Hello Skill

## When to use

Use when the user says hello or asks what a skill is.

## Instructions

1. Greet the user in one short sentence.
2. Explain that a skill is a folder of instructions that teaches an assistant one capability.
3. Offer to show the skill template at `skills/_template/SKILL.md`.

## Examples

**Input:** "Hi, what's a skill?"

**Output:** "Hello! A skill is a small folder of instructions that teaches an assistant one
capability. Want to see the template?"

## Limits

This is a documentation example only; it is not registered in `registry/skills.yaml`.
